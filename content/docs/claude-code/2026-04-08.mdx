> Claude CodeのSkillを作成しました。これを使うと、PDF、Word、PowerPointなどの複雑なドキュメント群に対して深い調査レポートを生成し、単語レベルの引用とバウンディングボックスを原文書に直接紐づけて返せます。
> 
> 「/research-docs」コマンドで起動します。
> 1. liteparseというツールで数秒で全ドキュメントのテキストと位置情報を抽出
> 2. それを基にHTMLレポートを生成し、各ページで引用部分が視覚的に確認可能
> 
> 通常のClaudeにも深い調査能力はありますが、根拠の追跡性が弱いという課題がありました。このSkillはその監査可能性を大幅に向上させます。実際に使えるリンクも公開しています。

**解説:**

LlamaIndexの共同創業者であるJerry Liu氏が開発した、実務で非常に有用なClaude Code Skillの詳細です。特にPDFなどの複雑文書を対象に、単なる要約ではなく「どの文書のどの単語に基づく主張か」を視覚的に追跡できるレポートを自動生成する点が革新的です。技術的には「liteparse」という高速解析ツールと組み合わせ、位置情報（bounding box）まで保持している点がポイントで、規制文書や法務資料、研究資料の分析など、正確性が求められる業務でのベストプラクティスとして参考になります。監査可能性という実務的な課題解決に焦点を当てた内容です。
