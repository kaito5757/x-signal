**投稿内容:**

> Claude Codeを毎日使っているなら、以下の12のコンセプトを理解すると非常に役立つでしょう。
> 
> 1. CLAUDE.md → プロジェクトの持続的な記憶（スタック情報、規約、制約を毎回自動読み込み）
> 2. Rules → プロジェクト全体に適用される行動ガードレール
> 3. Skills → 再利用可能な指示ファイル（.claude/skills/に保存し、該当タスクで自動適用）
> 4. Hooks → イベント発生時に実行されるシェルスクリプト（自動リント、テスト実行など）
> 5. Slash Commands → 1回のキーストロークで多段階ワークフローを起動
> 6. Plugins → スキル、フック、コマンド、MCPサーバーをまとめたインストール可能パッケージ（公式マーケットプレイスに100以上）
> 7. MCP → データベースやAPIなど外部サービスと接続し、コードベースを超えた実世界アクセスを実現
> 8. Plan Mode → コードに手を付ける前にステップバイステップの計画を立て、承認後に実行
> 9. Permissions → セッションごとにツールの許可/ブロックを厳密に制御（本番環境では必須）
> 10. Subagents → 複数のClaudeインスタンスを並行起動し、複雑なワークフローを分担
> 11. Voice Mode → 音声でハンズフリー操作（/voiceコマンド使用）
> 12. Rewind → セッション内の任意のチェックポイントに戻って再開
> 
> これらを組み合わせることで真価を発揮します。

**解説:**

Claude Code（AnthropicのCLIツール）を単なるコード生成チャットボットではなく、「プログラマブルな開発環境」として最大限に活用するための体系的なガイドです。CLAUDE.mdファイルでプロジェクトの文脈を永続化したり、SkillsやHooksで自動化を構築したり、Subagentsで並行処理を実現するなど、高度な設定が紹介されています。投稿者はこれらの要素を組み合わせる重要性を強調しており、初心者から上級者まで実践的なベストプラクティスとして非常に価値が高い内容です。引用元の英語投稿を基にスペイン語で要約・共有されたものがさらに日本語訳されています。
