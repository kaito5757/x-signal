> 
> 世界の名作プロダクト2,000件以上のデザイン言語を、Claude CodeやCodexが解釈できる「DESIGN.md」として一括ダウンロード可能に。
> 
> ・Linear、Notion、ElevenLabsなどのカラー、タイポグラフィ、余白ルールを完全にトークン化

Claude Codeや類似のAIコーディングツールで生成されるUIがしばしば「AIっぽくてダサい」と指摘される問題に対する解決策です。LinearやNotionなどの一流プロダクトから抽出した本格的なデザインシステム（色、フォント、余白、レイアウトルール）を、AIが理解しやすいMarkdown形式（DESIGN.md）にまとめたライブラリを提供しています。プロジェクトのルートにこのファイルを置くだけで、AIが次回の生成から洗練されたデザインを採用するようになります。複数のAIツール（Claude Code、Cursor、v0）に対応しており、Tailwind CSSを使った実装もサポート。AIを活用したフロントエンド開発における実践的なTipsとして、デザイン品質を大幅に向上させる手法です。
