> 主な変更点：
> ・disableSkillShellExecutionによりスキル内のインラインシェル実行を無効化し安全性を向上
> ・MCPで_meta["anthropic/maxResultSizeChars"]=500Kを指定可能になり、DBスキーマなどの大規模出力を切り捨てずに扱える

**解説:**

Anthropicの公式CLIツール「Claude Code」の最新バージョン2.1.91の変更点をまとめた投稿です。特に注目すべきは、スキル実行時のセキュリティ強化と、MCP（Model Context Protocol）で最大50万文字までの大規模結果を扱えるようになった点です。これによりデータベースの全スキーマを一度に渡したり、複雑なツール連携を安全に行ったりできるようになりました。バグ修正も含めて実務で使う開発者にとって重要なアップデート情報です。
