**投稿内容:**

> コーディングエージェント（Codex / Claude Code）を使う際に「◯◯を改善して」と言うとよくわからない結果になるんですが、「◯◯の問題があるので点数化するスキルを作成して」と伝えて、点数化するスキルをもとに「/goal 点数化したものを80点になるまで改善して」みたいに伝えるとうまくいきやすいです。

**解説:**

Claude CodeやCodexなどのAIコーディングエージェントに対して、曖昧な「改善して」という指示だと結果が散漫になりやすいという問題を指摘し、効果的な代替プロンプト手法を提案した技術Tipsです。

具体的な手順は、まず「この問題点を点数化するスキルを作成して」と指示して評価基準となるスキルを生成させ、そのスキルを使って「/goal コマンドで80点以上になるまで繰り返し改善させる」というもの。単なる指示ではなく、明確な評価軸をAI自身に作らせることで、目標指向の反復改善が可能になると説明しています。

多くの開発者が直面する「AIが迷子になる」現象に対する実践的な解決策として、シンプルながら再現性が高く、すぐに試せる内容です。エンゲージメントも高く、開発者コミュニティで共感を呼んでいます。
