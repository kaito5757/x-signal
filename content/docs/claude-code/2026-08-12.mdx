**投稿内容:**

> GraftはClaude Codeを自分のリポジトリで4倍安く、3倍速くする。
> 
> コードエージェントの根本問題は毎回ゼロから探索すること。リポジトリ全体を調べ、インポートを追跡し、ファイルをオープンし、戻る…これを毎セッション・毎開発者で繰り返し、トークンと時間を浪費する。
> 
> Graftはコードベースのマップを1回だけ構築し、リンクされたMarkdownファイル群に変換。エージェントはこれを直接読むだけ。
> 
> 効果：
> - タスクあたりツールコール46%減
> - トークン消費42%減
> - セッション時間60%減
> - SWE-bench正答率+10ポイント
> - Claude Code、Cursor、Codex、Geminiなど全エージェント対応
> - 埋め込み・DB・サーバー不要、Git内のファイルのみ
> 
> インストールは2コマンド：npm install -g @nanonets/graft と graft init。
> 
> 以前40秒かかっていた探索が、最初のプロンプトで即利用可能に。
> リポジトリはコメントに記載。

**解説:**

Claude Codeを含むAIコーディングエージェントの最大のボトルネックである「毎回のコードベース探索」を解決するツール「Graft」の詳細解説。1回限りのマップ構築でMarkdown化し、繰り返しコストを劇的に削減する仕組みと定量効果（トークン42%減、時間60%減、正答率向上）を具体的に示している。サーバーレスでGitに統合できる手軽さも魅力。技術Tips・ベストプラクティスとして優先度が高く、Claude Codeの実務効率を直接向上させる実用的な情報。
