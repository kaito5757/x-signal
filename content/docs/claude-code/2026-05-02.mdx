| リンク | [元ポスト](https://x.com/FredKSchott/status/2050274923852210397) |

**投稿内容:**

> FlueというTypeScriptフレームワークを紹介します。これはエージェント構築のための初の「Agent Harness Framework」です。
> Claude Codeに似ていますが、完全にヘッドレスでプログラマブル。人間の操作を前提とせず、TUIやGUIなしでTypeScriptだけで動作します。
> エージェントのロジックは主にMarkdown（skills, context, AGENTS.md）に記述。AstroやNext.jsのようなフレームワークとして、Node.jsやCloudflareなどどこでもデプロイ可能です。
> Astroリポジトリ内のAIワークフローのために開発され、一般公開に至りました。エージェントがライブラリからフレームワークに移行する時期に来ていると思います。

**解説:**

Claude Codeの体験をベースにしつつ、完全にプログラム可能でサーバーサイドやCI/CDに適したエージェント構築フレームワーク「Flue」の発表です。従来のAI SDKとは異なり、ハーネス（エージェントの制御機構）とサンドボックスを最初から組み込み、ファイル操作やシェルコマンド実行をネイティブにサポートします。ロジックをMarkdown中心に記述できる点が特徴で、開発者が少ないコードで自律型エージェントを作成・展開できる実践的なソリューションです。Astroの作者による開発という背景もあり、業界の動向としてエージェント開発の次のステージを示唆する内容となっています。
