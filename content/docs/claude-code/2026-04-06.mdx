> これを改善する習慣として以下の6点を紹介しています：

> 2. 最初に目標を完全に記述する（途中修正を減らす）
> 3. 固定コンテキストはCLAUDE.mdファイルにまとめておく
> 4. 使わないMCPサーバーは無効化する
> 5. タスクに合わせてモデルを選択（簡単な作業はHaikuで十分）
> 6. ピークタイムを避ける

**解説:**

Claude Codeを実際に長時間使う上でのベストプラクティスを技術的に詳しく解説した投稿です。コンテキストウィンドウの膨張がトークンコストと速度に与える影響を正確に指摘し、具体的な対処法を複数提示しています。特に「/compact」の定期使用やCLAUDE.mdの活用、モデル選択のアドバイスは実務で即役立つ内容で、初心者から上級者まで参考になる技術Tipsです。無駄なコストを抑えながら生産性を維持するための実践的な知見として優先度の高い情報と言えます。
