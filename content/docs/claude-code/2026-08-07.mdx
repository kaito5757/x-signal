**投稿内容:**

> RLMs（Recursive Language Models）は深さ1でも本物の再帰処理が可能だという話です。REPL環境にいるため、実際の再帰プログラムを書いてサブエージェントを呼び出せますが、サブサブエージェントは必要ありません。一方、Claude Codeではこれができません。ファイルにプログラムを書いて「claude -p」を実行するしかありません。

**解説:**

この投稿は、Claude Code（AnthropicのCLIツール）の現在の設計限界を具体的に指摘しています。REPL（対話型実行環境）ベースのRLMでは、コード内で自然に再帰呼び出しをしてサブエージェントを動かせますが、Claude Codeの場合、外部コマンド実行をファイル経由でしか実現できないため、真の再帰が制限されると説明。画像では実際の動作例を示しており、AIエージェント開発におけるアーキテクチャの違いを技術的に深掘りした内容です。業界動向として、単なるCLIツールを超えた「本物の再帰エージェント」実現に向けた議論を喚起しています。優先される技術Tipsとして、Claude Codeユーザーが再帰が必要なタスクではワークアラウンド（外部プログラム経由）を検討すべき点を明確に示しています。
