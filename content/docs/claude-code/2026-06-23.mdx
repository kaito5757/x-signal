> 
> - Claude CodeのCLIをNVIDIA NIM、OpenRouter、LM Studio、llama.cppなどに接続
> - Kimi、GLM、DevstralなどのオープンソースモデルをClaudeの代わりに実行

> このインターフェースで他のモデルを試すのは便利ですが、「Claudeが無料で使える」と勘違いしないよう明確に伝えておきます。リポジトリはこちらです。
