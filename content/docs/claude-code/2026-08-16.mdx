**投稿内容:**

> Claude Codeの最大の問題の一つが解決されました。
> 
> Graftというツールが開発され、エージェントが毎回プロジェクト全体を再読み込みするのを防ぎ、トークン消費、API呼び出し数、処理時間を大幅に削減します。
> 
> 無料、オープンソース、完全にローカルで動作します。
> 
> 仕組みを説明します👇
> 
> 1. Graftは何をするのか？
> Graftはリポジトリの「生きている地図」を作成し、Claude Codeなどのエージェントが作業開始前にアーキテクチャを理解できるようにします。
> ファイルの繰り返し読み込みの代わりに、ノードに要約、関係性、依存関係、重要なコード断片を生成し、プロジェクト変更時に同期を保ちます。
> 162回の制御された実行で、トークンを42%削減、ツール呼び出しを46%削減、時間を60%削減、コストを32%削減し、同じ正確性を維持しました。
> 
> 2. 動作の仕組み
> → プロジェクト構造を分析してコードのグラフを構築
> → システムの各関連部分にMarkdown形式のカードを生成
> → 要約、依存関係、ソースファイル、コンポーネント間の関係を保存
> → Claude Code、Cursor、Codex、Gemini、Copilotなど各種エージェントと統合
> 
> 3. インストール方法
> → プロジェクト内で `npx @nanonets/graft init` を実行
> → 使用するエージェントを検知し、接続するものを選択
> → Claude Codeにスキル、MCPサーバー、フック、リアルタイムステータスバーを追加
> → より深いLLM生成要約が必要なら `graft build --deep` を実行
> 
> リポジトリ: https://github.com/nanonets/graft

**解説:**

Claude Code（AnthropicのCLIベースのコーディングエージェント）はプロジェクトの文脈を毎回再読み込みするため、トークン消費が激しくなり、長時間の作業でコストと時間がかかるという課題がありました。この投稿では、新しくリリースされたオープンソースツール「Graft」がその問題を解決する具体的な方法を紹介しています。Graftはリポジトリ全体をグラフ構造でマッピングし、必要な要約や依存関係を事前に準備・維持することで、再読み込みを最小限に抑えます。実際のベンチマーク結果（トークン42%減、時間60%減など）を示しており、実践的なユースケースとして即座に役立つTipsです。インストールもシンプルで、Claude Codeだけでなく他のAIコーディングツールにも対応。業界の効率化動向を象徴する内容で、開発者の生産性を大幅に向上させる可能性を解説しています。

### 5. DeepSeek Harnessの文脈で語られるClaude CodeのHarnessとしての役割と将来性分析

**投稿内容:**

> この2日間でDeepSeek Harness（DSH）に関する多くの議論を見てきましたが、残念ながら99%の議論がDSHの本質を理解していません。
> 
> 多くの人はUIが粗く設定が複雑だと「失敗したAgent製品」と見なします。またCodexやClaude Codeと比較して「どのCoding Agentのワークフローが優れているか」を議論します。
> 
> しかしDSHの真の価値は、Harness層でのRecursive Self-Improvement（RSI：再帰的自己改善）を可能にするRuntimeを提供している点にあります。
> 
> Agent = Model + Harnessという観点で、CodexやClaude CodeはHarnessの拡張性（Skill、Plugin、Hookなど）を高めていますが、人間が主導で設計しています。
> 
> DSHは「Everything is a Plugin」とし、Model、Tool、Agent Loop、UIまでをモジュール化。Harness自体をAgentが観察・修正・検証できるように設計されています。
> 
> これにより、ModelとHarnessが相互に進化するループ（より良いHarnessが良いトレーニングデータを生成し、Modelを強化）が可能になります。
> 
> 論文「RHI（Recursive Harness Self-Improvement）」では、Harness改善により推理コストを60%削減し、主にコンテキスト管理と情報フローの最適化で性能向上した事例が示されています。
> 
> DSHは完成度が低く普通のユーザーにはおすすめしませんが、将来のAgentアーキテクチャの基盤となる実験プラットフォームとして重要です。半年後、突然人気のAgentが出て「実はDSH由来のアイデアだった」という可能性があります。
> 
> 過去は「Modelを最適化し、Harnessを後から合わせる」時代でしたが、未来はModelとHarnessが共同進化する時代です。

**解説:**

DeepSeek Harness（DSH）を題材に、Claude Codeを含む現代のCoding Agentの限界と将来性を深く分析した業界動向投稿です。Claude Codeを「人間主導のHarnessを持つAgent」の代表例として位置づけ、DSHが目指す「Agent自身がHarness（実行環境）を自己改善する」アーキテクチャの優位性を解説。技術論文の知見（コスト60%減、コンテキスト管理の重要性）を交え、ModelとHarnessの共同進化という大きなトレンドを分かりやすく説明しています。単なるツール比較を超えた分析で、AIエージェント開発の最先端動向を理解するのに適した内容です。Claude Codeユーザーが自身のツールの位置づけを再考するきっかけにもなります。
