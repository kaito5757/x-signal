> 
> 従来の問題点として、手動で動画をスクラブし、フックをメモしたりスクリーンショットを撮ったりする必要があり、10本見終わった頃には内容を忘れてしまう点がありました。

> - 動画ファイルをClaude Codeにドロップ
> - Gemini API経由でネイティブ動画理解を実行
> - フック分解、ターゲットオーディエンス、角度、ビートごとの分析、画面テキストの逐語記録を返却
> - 自社クリエイティブに応用できるパターンを抽出
> 
> 手動作業は一切不要。Geminiによる本物の動画理解、構造化された分析、タイムスタンプ付きテキスト、フックバリエーション生成、30分動画あたり約27セントで利用可能。すべてClaude Code内でGemini APIを使って構築しました。詳細な構築過程を録画し、スキルを無料で配布しています。「CLAUDE」とコメントしていいねを押せばDMで送ります（フォロー必須）。

**解説:**

Claude Code（AnthropicのCLI/エージェントツール）に動画解析機能を拡張する実践的な「スキル」を作成した事例です。従来の広告分析作業を大幅に効率化し、手動スクラブを排除。Gemini APIを組み合わせたハイブリッドアプローチで、単なる文字起こしではなく視覚・文脈理解を実現しています。DTC企業向けの具体的なユースケースとコスト（27セント/30分）、構築過程の共有、無料配布という成果報告が含まれており、技術Tipsと実践成果の両方を兼ね備えた優先度の高い投稿です。多くのユーザーが「CLAUDE」と反応してスキルを求めている点からも注目度が高い。
