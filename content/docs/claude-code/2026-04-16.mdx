**投稿内容:**

> Claude CodeのRoutines機能はDTCブランドにとってゲームチェンジャーです。プロンプト、リポジトリ、コネクターを一度設定すれば、Anthropicのクラウド上で任意のスケジュールで実行されます。ラップトップを閉じたまま、眠っている間もルーチンが動き続けます。
> 
> 毎朝の手動ワークフローを自動化するのに最適です。例えばMeta広告データ、GA4、Shopifyを自動で引き、7日・28日移動平均と比較して異常を検知し、朝6時にSlackに60秒のブリーフを投稿する「Daily Performance Analyst」ルーチンを作成できます。
> 
> さらに競合広告監視、クリエイティブ疲労分析、顧客レビュー抽出、エグゼクティブサマリーなど様々なワークフローを構築可能。既存のClaude Codeスキルも自動でルーチン内で動作します。
> 
> 設定手順、5つのDTC具体例プロンプト、スキルとルーチンの組み合わせプレイブックを無料で提供中です。

**解説:**

Anthropicが前日に研究プレビューとして発表した「Routines」機能を、DTC（Direct-to-Consumer）ブランドのマーケティング視点で実践的に解説した投稿です。従来は手動で毎朝繰り返していたデータ収集・分析・報告を、クラウド上で完全自動化できる点を強調。ラップトップ常時稼働の必要がなくなる点が大きなメリットで、具体的なプロンプト例やワークフロー構築のヒントを提供しており、技術Tipsと実践的ユースケースの両方を兼ね備えています。エンゲージメントも高く、業界動向としての価値が高い内容です。

> 
> トリガーは3種類：スケジュール（毎時/夜間/週次）、APIエンドポイント（POSTで即時起動）、GitHubイベント（PR・pushなどのwebhook）。1つのルーチンに複数トリガーを同時設定可能です。
> 
> 利用上限はプランにより異なり（Pro:5回/日、Max:15回/日、Team/Enterprise:25回/日）、以前より自動化設定数が増加しています。長らく愛用していましたが、このアップデートは非常に嬉しいものです。

**解説:**

Anthropicの公式新機能「Routines」の詳細を日本語で速報・解説した投稿です。クラウド実行による常時稼働環境不要化、3種類のトリガー設定、利用上限などの具体的な技術情報を整理して提供しており、新機能・アップデート情報として優先度が極めて高いです。日本語話者向けに実用的な観点（Mac Mini不要など）も補足されており、Claude Codeユーザーにとって即戦力となるベストプラクティス的な内容です。
