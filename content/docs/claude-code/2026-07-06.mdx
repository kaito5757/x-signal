Claude Code（特にFable 5モデル）と動画生成ツールCreatifyをMCP（おそらくツール連携機能）で統合し、ターミナルだけで広告動画を自動生成する先進ワークフロー。ブランド情報をURLから自動抽出したり、記憶を共有したりする仕組みにより、従来の手作業を劇的に削減。マーケティング担当者向けの実践的ユースケースで、AIエージェントが単なるコード生成を超えてビジネスプロセス全体を変えるトレンドを具体的に示している。動画デモ付き。
