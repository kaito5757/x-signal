> 
> 具体的な機能：朝にカレンダー/Slack/Gmailから日報自動作成、夕方に1日の行動パターン検出、記事やツイートの自動要約・Obsidian蓄積、XブックマークやSlack DMからの自動クリップなど。PCを閉じていても動作し、iPhoneで閲覧可能。
> 
> 核心はSOUL.md（価値観）、MEMORY.md（経験・学び）、DREAMS.md（目標・問い）の3ファイル。Karpathy提唱の「LLM Wiki」を実装したものです。設計思想、図、セットアップ手順、日本語README完備で初心者でも試せます。

**解説:**

Claude Codeを活用した実践的な「第二の脳」構築事例を公開した投稿です。日常の情報収集・振り返りをAIに任せるシステムで、3つのMarkdownファイルに自分の価値観・記憶・夢を記述し、AIが毎日それらを読み込んでパターン検出や自動記録を行う仕組みが特徴です。Karpathyのアイデアを具現化した点や、Obsidianとの連携によるグラフビュー活用など、具体的なユースケースと成果が明確。日本語での丁寧なドキュメント提供も評価され、実践的なユースケース報告として選出されました。
