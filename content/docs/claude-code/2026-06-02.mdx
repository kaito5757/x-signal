### 2. Claude Codeのトークン使用量を半分に削減する実践的モデルルーティング手法

| 項目 | 詳細 |
|------|------|
| 投稿者 | marcus (@marcusyul) |
| 投稿日時 | 2026年6月2日 22:23（日本時間） |
| エンゲージメント | ❤️ 225 / 🔁 36 / 💬 17 |
| リンク | [元ポスト](https://x.com/marcusyul/status/2061438510381306012) |

**投稿内容:**

> Claude Codeのトークン使用量を1週間計測した結果、1つの設定ファイルだけで半分に削減できました。
> 
> 秘訣はClaudeに「タスクに応じて最適なモデルを選ばせる」ことです。
> - 機械的な大量作業 → Haiku
> - 調査・コード探索・要約 → Sonnet
> - 本格的な推論や複雑なトレードオフ → Opusのみ
> 
> 以前はすべての作業に高性能モデルを使い無駄に消費していましたが、同じ成果を半分のコストで出せます。
> 
> 設定は3つのブロックで構成：
> 1. タスク委譲ブロック：サブエージェント生成時に最も安価で十分なモデルを選択させる。Haikuは自身でサブエージェントを作らない、上限深度は2レベル。
> 2. 優先ツールブロック：無料・低コストツール（WebFetch、agent-browser CLI、pdf to textなど）を優先。繰り返しパターンは再利用可能なツールにカプセル化。
> 3. settings.jsonの2行追加：
>    - "CLAUDE_CODE_DISABLE_1M_CONTEXT": "1"（不要な巨大コンテキストを防止）
>    - "CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "80"（80%で自動圧縮）
> 
> 設定は2分で完了。以降すべてのタスクで節約効果が積み重なります。

**解説:**

Claude Codeを実際に1週間運用して得た、非常に実践的なコスト最適化Tipsです。Anthropicの異なるモデル（Haiku/Sonnet/Opus）の強みを活かした「モデルルーティング」と、低コストツールの優先使用、コンテキスト管理の工夫を組み合わせることで、トークン消費を50%削減した具体的な成果を報告しています。技術的な内容をステップバイステップで解説しており、単なるTipsではなく再現性の高いベストプラクティスとして価値が高いです。優先すべき「具体的な技術Tips・ベストプラクティス」に完全に合致する投稿です。
