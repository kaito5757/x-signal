**投稿内容:**

> Claude CodeやCodexを使っている場合、エージェントが従うべきSpec-Driven Development（SDD）の流れは次の通りです：
> 
> 1. リサーチ：問題を理解し、関連ドキュメントやコードを確認する。
> 2. 設計：複数の解決策を考え、トレードオフを比較して最適なものを選ぶ。
> 3. 仕様策定：要件、範囲、受け入れ基準を明確にする。
> 4. 計画：実装を小さなタスクに分割する。
> 5. 実装：1つのタスクずつ解決する。
> 6. 検証：テストを実行し、仕様を満たしているか確認する。
> 
> 問題理解と計画に時間をかければ、エージェントが実装中に即興で判断する回数が減ります。

**解説:**

Claude Code（AnthropicのCLIベースのAIコーディングツール）を使った開発で、AIエージェントを効果的に活用するための「仕様駆動型開発（SDD）」の具体的なステップを解説した投稿です。単にコードを書かせるだけでなく、リサーチから検証まで構造化されたプロセスを提案しており、AIが勝手に判断してミスをするリスクを減らすベストプラクティスとして役立ちます。計画段階を重視することで、AIの出力をより信頼性高くコントロールできる点が実践的で、業界でのAI活用動向を示す好例です。
