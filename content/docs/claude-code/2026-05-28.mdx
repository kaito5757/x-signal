**投稿内容:**

> Claude Codeだけでブランド付きInstagramカルーセル生成ツールを作りました。
> 
> ブランドURLと商品名を1つ入力するだけで、6枚の完成したカルーセルスライドが生成されます。通常エージェンシーが2000ドル請求するクオリティです。
> 
> 従来の手作業（Notionでコピー執筆、Canvaでデザイン、1枚ずつエクスポート、クリエイティブチームとの修正往復）をすべて排除。
> 
> Claude Codeの流れ:
> 1. ブランドURLからサイトをスクレイピングし、色・フォント・トーン・ポジショニングを自動抽出
> 2. 実績のあるカルーセルフレームワークに基づいて6つのスライド案を生成
> 3. 各スライドの詳細な画像プロンプトを作成
> 4. FAL経由でChatGPT Images 2.0に並列送信して画像生成
> 5. 完成スライドをダウンロードし、HTMLギャラリーで確認
> 
> Canvaもデザイナーも不要。ブランドに正確に合った1080x1350pxのスライドが3分で完成します。プレイブックも無料配布中です。

**解説:**

Claude Code（CLIツール）を活用した実践的なユースケース報告です。単なるコード生成ではなく、ウェブスクレイピング・画像プロンプト生成・並列API呼び出し・自動ダウンロードまで一貫したパイプラインを構築した事例で、DTCブランドや代理店が活用できる具体的な成果を示しています。従来の手作業を劇的に効率化するワークフローを丁寧に解説しており、技術Tipsとして非常に参考になる内容です。エンゲージメントも高く、読者がすぐに真似できる実用性が評価されています。
