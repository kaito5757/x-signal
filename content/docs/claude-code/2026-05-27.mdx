### 1. Claude Codeの新セキュリティプラグイン公開

| 項目 | 詳細 |
|------|------|
| 投稿者 | ClaudeDevs (@ClaudeDevs) |
| 投稿日時 | 2026年5月27日 6:24（日本時間） |
| エンゲージメント | ❤️ 303 / 🔁 23 / 💬 17 |
| リンク | [元ポスト](https://x.com/ClaudeDevs/status/2059385239781384341) |

**投稿内容:**

> Claude Code向けのセキュリティガイダンスプラグインをリリースしました。コードを書いている最中に脆弱性を特定し、修正を支援します。
> 
> すべてのClaude Codeユーザーが利用可能で、プラグインマーケットプレイス（/plugins）からインストールできます。
> 
> このプラグインはフック経由で動作し、3つのレベルでコードをレビューします。
> - ファイル編集時：危険なライブラリの誤用などのリスクパターンを検知
> - モデルターン後：完全な差分をレビューして見逃しやすい問題を特定
> - コミット時：周辺コードを読み込んで脆弱性を検証
> 
> Anthropic内部での広範な使用とベンチマークにより、プラグイン使用時のPRでのセキュリティ関連コメントが30-40%減少しました。
> 
> 組織独自のルールはclaude-security-guidance.mdファイルで追加可能。リポジトリに配置するかMDMで配布できます。
> 詳細ドキュメント：https://code.claude.com/docs/en/security-guidance

**解説:**

Anthropic公式アカウントによる新機能発表です。Claude Code（AnthropicのCLIベースのAIコーディングツール）に統合されるセキュリティプラグインの詳細を説明しています。リアルタイムでコードの脆弱性を検知・修正する仕組みを3段階（編集時、モデル応答後、コミット時）で実装し、内部ベンチマークでPR時のセキュリティ指摘を大幅に削減した成果を報告。組織独自ルールも追加可能で、実務でのセキュリティ強化に直結する実践的なアップデート情報です。優先すべき「新機能・アップデート情報」の最上位に該当します。

> Claude Codeを非技術的な仕事に使う基本的なコツは、複数のファイルを1つのフォルダにまとめ、「スクリプトを書け」「HTMLを作成せよ」と指示することです。
> 
> - 画像・動画編集 → スクリプト作成
> - 財務・税務作業 → PDFを入れ、スクリプトでHTML出力
> - 医療関連の相談 → PDFとデータを入れ、HTMLで出力
> - 書類作成 → スクリプト作成
> - レポート作成 → HTML生成
> - 計画立案 → HTMLで視覚化
> 
> データへのアクセスも重要で、GmailやGoogle Calendarなどのコネクタも追加してください。多くの人はファイルにどれだけ豊富なコンテキストがあるかを過小評価しています。

**解説:**

Claude Codeの開発者本人が、非エンジニアが同ツールを活用するための実践Tipsを共有しています。複雑なプロンプトエンジニアリングではなく、「フォルダにファイルをまとめてHTMLやスクリプトを出力させる」というシンプルなアプローチを提案。さまざまな業務シーンでの具体例を挙げ、ファイルベースのコンテキスト提供と外部ツール連携の重要性を強調しています。技術者以外でも使える「具体的な技術Tips・ベストプラクティス」として非常に価値が高く、エンゲージメントも高い投稿です。
