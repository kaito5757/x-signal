### 1. Claude Codeのスクリーンリーダーモードが新登場

| 項目 | 詳細 |

| 投稿者 | ClaudeDevs (@ClaudeDevs) |
| 投稿日時 | 2026年7月21日 6:20（日本時間） |

| リンク | [元ポスト](https://x.com/ClaudeDevs/status/2079315549163778366) |

**投稿内容:**

> Claude Codeにスクリーンリーダーモードが追加されました。
> 
> `claude --ax-screen-reader` を実行すると、視覚的なターミナルUIを、VoiceOverやNVDAなどのスクリーンリーダーが読みやすいプレーンテキストの直線的な形式に切り替えます。
> 
> また、ラベル付きの行（you:、claude:、tool:）を追加し、番号付きメニューは数字で回答可能、Claudeが必要なときにベルを鳴らす機能もあります。
> 
> `~/.claude/settings.json` に "axScreenReader": true を追加するか、環境変数 CLAUDE_AX_SCREEN_READER=1 を設定すると常時有効にできます。
> 
> 詳細ドキュメント: https://code.claude.com/docs/en/accessibility

**解説:**

Anthropicの公式開発者アカウントから、Claude Code（AnthropicのCLIツール）のアクセシビリティ向上に関する新機能が発表されました。このモードは、視覚に障害のあるユーザーがスクリーンリーダーでClaude Codeを快適に操作できるように設計されています。従来のグラフィカルなターミナル表示をシンプルなテキスト出力に変更し、対話部分に明確なラベルを付け、メニュー選択を数字入力で可能にし、必要時に音で通知する工夫が施されています。設定方法も柔軟で、JSONファイルや環境変数で永続化可能です。アクセシビリティを重視したアップデートとして、開発者コミュニティから高い評価を集めています。
