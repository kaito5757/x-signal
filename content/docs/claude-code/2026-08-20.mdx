> 非エンジニアがClaude Codeを使って気軽にVercelなどで社内アプリを公開するのはなぜ危険か？Vercel自体は強固なセキュリティを提供していますが、Webアプリを簡単にインターネット公開できるため、セキュリティ知識が不足した人がサーバー・API・データベースを持つアプリを公開できてしまいます。
