**投稿内容:**

> 長期間Claude Codeを使い続けると、記憶ファイル（MEMORY.mdなど）に重複や古い情報が蓄積して混乱を招く。これを防ぐための「memory-dream」というプレイブックを作成した。Anthropicの公式「Dreams」機能をgitベース環境で再現する手順で、4つのフェーズ（採掘・統合・重複排除・剪定）で記憶を整理する。具体的なチェックリストと成果物の書き方も詳細に記載している。

**解説:**

Claude Codeや類似エージェントを長期間運用する際に発生する「記憶の劣化」問題に対する実践的な解決策。セッションが20〜30回を超えるとノイズが増えるため、定期的に記憶を再構成する手順書（playbook）を公開した。相対日付の絶対日付への変換や上位レイヤのルール尊重など、技術的ベストプラクティスが細かく記載されており、実際にClaude Codeをプロダクションで使っている開発者から高い評価を得た具体的なTips投稿である。
