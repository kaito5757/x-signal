**投稿内容:**

> Claude Code Maxを使う際の私のTips: alias c='CLAUDE_CODE_AUTO_COMPACT_WINDOW=400000 claude --dangerously-skip-permissions' を設定せよ。1Mコンテキストウィンドウの40%で自動圧縮し、レスポンスを高速化しつつ実務レベルのタスクを十分に保持できる。モデルはopusplan + fastMode: trueと組み合わせるのがおすすめ。

**解説:**

Claude CodeのMaxプランで大規模コンテキスト（100万トークン）を使う際の効率化テクニックを紹介。環境変数で自動圧縮の閾値を40%に設定し、不要なコンテキストを定期的にクリアすることで速度を維持しつつ、実用的なタスクを処理できるようにするものです。モデル選択（opusplan）とfastModeの併用でさらに最適化。実際のユーザー体験に基づく具体的なコマンドと設定値が記載されており、トークン消費やレスポンス速度に悩む開発者にとって即実践可能なベストプラクティスです。コメントでも追加Tips（clearContextOnPlanAcceptなど）が寄せられています。
