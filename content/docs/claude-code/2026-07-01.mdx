> Claude Sonnet 5が登場しました。Sonnet価格帯で最高レベルのコーディングとツール使用性能を発揮し、100万トークンのコンテキストウィンドウを備えています。Proユーザー向けにClaude Codeの新しいデフォルトモデルとなり、Claudeプラットフォーム全体（APIやManaged Agentsを含む）で利用可能です。

>

> 複数モデル構成でも効果的。より高性能モデルで計画立案しSonnet 5で実行、または逆のパターンも可能。Claude Managed AgentsではSonnet 5と高性能サブエージェントを組み合わせられます。
> 
> Sonnet 5への移行を容易にする「claude-api」スキルも提供。プロンプト調整、努力レベル推奨、アドバイザモード設定を支援します。

AnthropicがClaude Sonnet 5をリリースしたことを公式開発者アカウントが詳細に解説した投稿です。Claude Code（AnthropicのCLIツール）の新デフォルトモデルとしてSonnet 5が採用され、1Mトークンコンテキストと向上したエージェント性能が強調されています。特に「適応型思考」の導入により、従来の固定思考モードから動的に調整されるようになり、実際の開発現場で長時間実行されるコーディングタスクの信頼性が大幅に向上した点が技術的に重要です。価格面では期間限定プロモーション（入力$2/M、出力$10/M）も発表され、導入しやすくなったアップデート情報として優先度が高い内容です。
