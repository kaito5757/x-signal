>

> 
> エージェントはストリームを接続し、Live Eventsを監視し、エラーが発生した関数を書き換えます。実際のイベントに対して修正を実行してから適用するため、何も永続化されません。
> 
> すべての変更はmcpタグ付きの監査ログに記録されるため、エージェントが行ったことと人間が行ったことを区別できます。
> 
> すべてMITライセンスで、自分の環境で動作します。
> 
> JitsuはGitHubスター5,000超の急成長オープンソースCDPです。イベント収集は無制限・無料、200kイベント/月までは配信も無料です。
> 
> 「Jitsu」とコメントすれば、Claude Codeでエンドツーエンドのイベントパイプラインを構築する際に私が実際に使っているプロンプトをお送りします。
