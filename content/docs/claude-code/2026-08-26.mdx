| 投稿日時 | 2026年8月26日 0:34（日本時間） |

| リンク | [元ポスト](https://x.com/tobi/status/2092259436538495186) |

**投稿内容:**

> ShopifyでClaude Codeを禁止するまで、AGENTS.mdや.agents/skillsなどのファイルを読み込むよう考えを変えないつもりだ。CLAUDE.mdだけに固執すると、チームメンバーが異なるツールを使う際に「脳裂（split brain）」の問題が発生する。これは全く不要なことだ。

（スレッド続き）  
複数の開発者が同時にCodex、Cursor、Claude Codeなど異なるAIコーディングツールを使う企業では、統一されたプロジェクト規約ファイルが必要。Claude Codeが独自のCLAUDE.mdにこだわることで、同一リポジトリ内で異なるルールが適用され、Agentの動作に矛盾が生じる。数千の開発者がいる大規模モノレポでは、ファイルの欠落が「一部の開発者だけ機能制限を受ける」事態を招く。

**解説:**

Shopify CEOのTobi Lütke氏が、Claude Code（AnthropicのCLIツール）がAGENTS.mdなどの業界標準的な設定ファイルを無視し、CLAUDE.mdのみを優先する仕様を強く批判した投稿です。企業レベルでのマルチAgent環境では、統一された「プロジェクト指示ファイル」が必須なのに、Claude Codeだけ独自仕様に固執することでメンテナンス負担と動作の不整合（split brain）が発生すると指摘。AnthropicのエンジニアThariq氏が「モデルファミリーごとに最適なシステムプロンプトが異なるため」と説明しつつ、「よりハックしやすくする（hackable）アップデートを準備中」と返答した点も重要です。これは単なるファイルフォーマットの好みの問題ではなく、AIコーディングツールが企業導入される際に避けられない「標準化 vs 独自最適化」の業界動向を象徴する議論として注目を集めました。
