**投稿内容:**

> Claude Codeは今、金融データセットに数秒で接続できるようになりました。金融リサーチ、企業データ、17,000以上の株式などにアクセス可能です。60秒以内に接続する方法は以下の通りです。
> 
> 1. Claude Codeを開いて以下を貼り付け：
> 「claude mcp add --transport http financial-datasets https://mcp.financialdatasets.ai/」
> 
> 2. 認証を行う
> Claude Code内で「/mcp」と入力し、ブラウザでOAuthフローを完了させます。いつでも「claude mcp list」で接続を確認できます。
> 
> 3. プロンプトを開始
> 例：「Appleの現在のPERと時価総額は？」「Teslaの直近4四半期の損益計算書を見せて」「Bitcoinの価格は過去1年でどう変わった？」
> 
> 4. ヘルプが必要な場合
> エラーが出たらClaudeに公式ドキュメントをスキャンさせて助けてもらえます。

**解説:**

Claude Code（AnthropicのCLIツール）にMCP（Model Context Protocol）という機能を使って外部の金融データAPIを簡単に接続する方法を紹介した投稿です。従来は別ツールでデータを集めていた金融分析が、Claude Code内で直接行えるようになり、ワークフローが大幅に効率化されます。具体的なコマンドとプロンプト例が記載されており、実践的なTipsとして価値が高い内容です。MCPはClaude Codeの拡張性を高める新機能の一つで、外部ツールやデータをAIエージェントにシームレスに取り込める点が注目されています。

### 4. Claude Codeを本格的な開発チームのように運用する5つのフォルダ構成

| 項目 | 詳細 |
|------|------|
| 投稿者 | Alvaro Cintas (@dr_cintas) |
| 投稿日時 | 2026年5月8日 0:55（日本時間） |
| エンゲージメント | ❤️ 164 / 🔁 20 / 💬 11 |
| リンク | [元ポスト](https://x.com/dr_cintas/status/2052417046789714123) |

**投稿内容:**

> Claude Codeをフル開発チームのように動作させる設定方法：
> 
> 5つのフォルダだけで完結します。
> 
> 1. CLAUDE.md → 記憶。リポジトリの憲法のようなもの。命名規則、構造、期待値を定義。プロジェクト全体で共有するグローバルファイルと各リポジトリ用のローカルファイルがあります。
> 
> 2. skills/ → 知識。再利用可能なワークフローを格納。タスク内容にマッチするとClaudeが自動で呼び出します。スラッシュコマンドは不要です。
> 
> 3. hooks/ → ガードレール。ツール呼び出しの前後に実行されるシェルスクリプト。危険コマンドのブロック、保存時の自動リント、デプロイ時のSlack通知など、決定論的な制御を行います。
> 
> 4. subagents/ → 委任。独立したコンテキストを持つサブエージェント。差分のみを見るコードレビュー担当や、独自権限を持つテスト実行者など、メインセッションをクリーンに保ちます。
> 
> 5. plugins/ → 配布。システム全体を1つのインストールパッケージにバンドル。同僚全員が同じスキル・フック・エージェントを使えるようにします。
> 
> これが「Agent Development Kit」です。5層のスタックで構成されています。

**解説:**

Claude Codeを単なる個人アシスタントではなく、CEO、エンジニア、デザイナー、QAなど役割分担されたチームとして機能させるためのベストプラクティスを体系的にまとめた投稿です。CLAUDE.mdでプロジェクトの「憲法」を作り、skillsで知識をモジュール化、hooksで安全性を確保、subagentsで並行処理を実現する手法は、規模の大きな開発プロジェクトで特に有効。技術的な深さと実用性を兼ね備えており、Claude Codeを本番環境で活用するための具体的なアーキテクチャとして参考になります。
