**投稿内容:**

> Claude CodeにRCE（リモートコード実行）の深刻な脆弱性が見つかった。
> 
> 悪意のあるdeeplinkをクリックさせることで、被害者のマシン上で任意のコマンドを実行可能だった。
> 
> この脆弱性はClaude Code v2.1.118で既に修正済み。
> 
> 原因はコマンドライン引数パーサーの不備で、--settingsなどのフラグを初期化前に解析する仕組みに問題があった。

**解説:**

AnthropicのClaude Code CLIツールに見つかったセキュリティ脆弱性について報じた投稿です。deeplink（claude-cli://）を悪用されると、ユーザーがクリックしただけで攻撃者にマシンを乗っ取られる可能性があった深刻な問題ですが、既に修正版がリリースされています。技術的な原因（eagerParseCliFlag関数）も説明されており、セキュリティ意識の高い開発者にとって重要な業界動向情報です。ツールを使う上での注意喚起として優先度の高い内容です。
