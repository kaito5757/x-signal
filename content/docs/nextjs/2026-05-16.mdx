### 1. Next.jsの重大なSSRF脆弱性（CVE-2026-44578）が修正

| 項目 | 詳細 |
|------|------|
| 投稿者 | Cyber Security News (@The_Cyber_News) |
| 投稿日時 | 2026年5月15日 16:29（日本時間） |
| エンゲージメント | ❤️ 705 / 🔁 149 / 💬 24 |
| リンク | [元ポスト](https://x.com/The_Cyber_News/status/2055188898545123576) |

**投稿内容:**

> ⚠️Next.jsの重大な脆弱性により、クラウド認証情報、APIキー、管理パネルが暴露される危険性があります。
> 
> 自己ホスト型のNext.jsアプリケーションでは、Server-Side Request Forgery（SSRF）の脆弱性を悪用され、内部ネットワークに侵入される可能性があります。
> 
> この脆弱性（CVE-2026-44578）は、Next.jsの組み込みNode.jsサーバーがWebSocketアップグレードリクエストを処理する方法に起因します。
> 
> 自己ホスト環境を使用している組織は、即時パッチ適用が必要です。

**解説:**

Next.jsの自己ホスト環境（Vercel以外で自前サーバーで運用する場合）で発見された深刻なセキュリティ脆弱性について報告した投稿です。攻撃者はWebSocketのUpgradeヘッダーを悪用して内部サーバー（例: AWSのメタデータエンドポイント）にアクセスし、クラウド認証情報やAPIキーを盗むことが可能でした。複数のCVEが同時に修正された最近のNext.jsアップデートで対応されており、セキュリティ研究者による発見と迅速な修正が強調されています。自己ホストユーザーは特に注意が必要で、フレームワークのセキュリティ動向を注視する重要性を示す実例です。
