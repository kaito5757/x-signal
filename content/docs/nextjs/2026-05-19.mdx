### 1. TanStackがReact Server ComponentsでNext.jsを上回る可能性を示唆

| 項目 | 詳細 |
|------|------|
| 投稿者 | Adam Rackis (@AdamRackis) |
| 投稿日時 | 2026年5月18日 23:31（日本時間） |
| エンゲージメント | ❤️ 250 / 🔁 6 / 💬 4 |
| リンク | [元ポスト](https://x.com/AdamRackis/status/2056382273318977893) |

**投稿内容:**

> TanStackのReact Server Components（RSC）実装がNext.jsを圧倒した（rsc-mogged）。詳細はブログ記事を読んでください。  
> リンク：https://frontendmasters.com/blog/react-server-components-in-tanstack/

**解説:**

React Server Components（RSC）は、サーバー側でコンポーネントをレンダリングすることで、クライアント側のJavaScriptを大幅に削減し、パフォーマンスを向上させるReactの先進機能です。この投稿では、TanStack（状態管理やクエリライブラリで有名なライブラリ群）が独自にRSCを実装し、Next.jsのRSC処理を上回る（「mogged」=圧倒した）ことを主張しています。添付画像はベンチマーク結果を示唆しており、作者はFrontend Mastersのブログで詳細を解説。Next.jsのApp Routerユーザーにとって、代替アプローチとして参考になる技術的な議論を喚起する内容です。RSCの根本的な理解（「コンポーネントはすでにレンダリング済み」）を繰り返し強調する作者のスタイルも特徴的です。
