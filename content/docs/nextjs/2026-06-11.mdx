### 1. AIを活用した高精度LP実装でNext.jsの強みを活かす実践例

| 項目 | 詳細 |
|------|------|
| 投稿者 | スモビジ開発ラボ (@yoshio_nocode) |
| 投稿日時 | 2026年6月10日 16:54（日本時間） |
| エンゲージメント | ❤️ 599 / 🔁 36 / 💬 8 |
| リンク | [元ポスト](https://x.com/yoshio_nocode/status/2064617130046452023) |

**投稿内容:**

> Claude Fable 5が凄すぎる。Image2で生成したLP画像をNext.jsで再現させたら一致度が圧倒的だった。
> 
> GPT5.5よりも全然一致度が高いし、マーケ戦略脳&文章力も強いので、
> 
> LP制作はClaude Codeを基盤にしつつ、画像生成だけClaude CodeからCodexを呼び出すのが良さそう。
> 
> 試したい人は以下のプロンプトがお勧めです↓
> 
> /goal 添付画像のLPをNext.jsで実装。再現度95%以上になるまで。
> 画像以外の手段だと再現が難しそうな箇所は適切に素材をimage_genで画像生成しながら作成して。
> 
> - アイコンや画像はなるべく元の画像と一致させること。
>   元画像から該当部分をクロップして参考画像としてimage_genに渡しつつ生成する
>   （codex exec は -i で参照画像を渡し、プロンプトは標準入力で渡す）
> - レスポンシブ対応すること。375〜1440pxの各幅で検証し、
>   横スクロールがないだけでなく、要素の重なり・見切れもないこと
>   （固定幅カードは w-full max-w-[Npx]、絶対配置レイアウトは広い幅のみで発動）
> - Playwrightでスクショ→元画像と比較→修正のループを回し、
>   npm run build が通ったら完了

**解説:**

AI画像生成ツール（ClaudeのImage2機能）で作成したランディングページ（LP）のデザイン画像を、Next.jsで忠実に再現するワークフローを紹介した投稿です。従来のGPTモデルよりClaude Fable 5の方が画像再現度が高く、マーケティング的な文章生成力も優れている点を強調しています。

具体的なプロンプト例では、再現度95%以上を目標に、画像生成とコード生成を組み合わせ、Playwrightを使った自動検証・修正ループを回す実践的な手法を詳述。レスポンシブ対応の細かいCSSテクニック（max-w指定や絶対配置の制御）も記載されており、AI×Next.jsの実務的なベストプラクティスとして非常に価値の高い内容です。AIエージェントを活用した現代的なフロントエンド開発のトレンドを体現した事例と言えます。
