**投稿内容:**

> Codex CLI 0.131.0 がリリースされました。
> 
> 主な変更点:
> - Python SDKをopenai-codex / openai_codexに移動。実行時に生成される型を固定し、同時ターンルーティングと承認モードを追加
> - 新コマンド「codex doctor」を追加。ランタイム、認証、端末、ネットワーク、設定、ローカル状態の診断をサポート向けに提供
> - TUI（テキストユーザーインターフェース）に統合トークン使用量、権限/承認モード、有効なワークスペースルートを表示。レスポンシブなMarkdownテーブルを追加
> - @メンションがファイル、ディレクトリ、プラグイン、スキルに対応した統一ピッカーになりました
> 
> （スレッド続き：TUIのステータスライン強化、プラグインピッカーの統合、remote-controlの改善、Python SDKのAPI明確化、さまざまなバグ修正。詳細はGitHubリリースノート参照）

**解説:**

OpenAIのCLIコーディングツール「Codex CLI」の最新バージョン0.131.0の公式リリース情報です。このアップデートは開発者の日常的な使い勝手を大幅に向上させる内容で、特に「codex doctor」という診断コマンドが注目されています。これはエージェントが動作しなくなったときに、認証問題や設定ミス、ネットワーク状態などを一括でチェックできるツールで、「デバッガーをデバッグする」手間を減らす実践的な機能です。また、TUIの表示が充実し、トークン消費量や承認モードが一目でわかるようになったことで、長時間の「vibe coding」（直感的なAI支援コーディング）がより快適になります。Python SDKの構造変更や@メンションの改善も、プログラマーがより効率的にAIエージェントを操作するための重要な進化です。新機能・アップデート情報として優先度の高い投稿です。
