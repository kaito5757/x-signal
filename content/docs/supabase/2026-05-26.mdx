| 項目 | 詳細 |

| 投稿者 | Supabase (@supabase) |
| 投稿日時 | 2026年5月25日 23:35（日本時間） |
| エンゲージメント | ❤️ 303 / 🔁 15 / 💬 15 |
| リンク | [元ポスト](https://x.com/supabase/status/2058919774051053834) |

**投稿内容:**

> コードベースでgetUser()を使っている場合、ほとんどのケースでgetClaims()に置き換えることができます。これによりアプリの速度が向上し、データベースの負荷を大幅に軽減できます。

**解説:**

Supabase公式アカウントによる実践的な技術Tipsです。Supabase Authを使っている開発者向けに、ユーザー情報を取得する関数を`getUser()`から`getClaims()`へ変更することを推奨しています。`getClaims()`はJWTトークンに含まれるクレーム情報を直接利用するため、データベースへの追加クエリが発生せず、レスポンスが高速化され、DB負荷が減ります。特にユーザー数が多いアプリケーションや頻繁にユーザー情報を確認する場面で効果的です。スレッドの続きはなく、シンプルで即適用可能なベストプラクティスとして多くの開発者に支持されています。
