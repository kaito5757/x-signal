**投稿内容:**

> 📣 TypeScript 7のリリース候補版が公開されました！  
> 新しいネイティブ版（Go言語で移植されたコンパイラ）がもうすぐ正式リリースされます。皆さんのコードベースでぜひ試してみてください。7.0リリースに向けてチームの準備を進めましょう！

> - `--watch`モードの完全再構築（Parcelのファイル監視をGoで移植し、アイドル時のCPU使用量を大幅削減）  
> - エディタ機能の強化（自動インポート、インラインヒント、コードレンズ、JSXリンク編集、セマンティックハイライト、未使用インポートの削除など）  
> - エディタのメモリ最適化（アイドル時に未使用の型チェックワーカーを解放）  
> - ビルドの並列化強化（`--checkers`で型チェックワーカーの数、`--builders`でプロジェクト参照の並列ビルドを制御可能）  
> - TypeScript 6.0の非推奨機能がエラーになる  
> - 6.0版と7.0版を並行して使用するための`@typescript/typescript6`パッケージ提供  
>   
> インストール方法：`npm install -D typescript@rc`

**解説:**

TypeScriptチーム公式による重大発表です。TypeScript 7.0の最大の目玉は、従来のTypeScriptコンパイラをGo言語に移植した「ネイティブポート」です。これによりビルド速度が最大10倍に向上し、パース・出力・型チェックを並列で処理できるようになりました。特に大規模プロジェクトやモノレポで効果が大きく、アイドル時のCPU・メモリ消費も大幅に改善されています。  
エディタ体験も大幅強化され、開発効率がさらに向上する内容です。正式リリース前に全ユーザーに試用を呼びかけており、開発者コミュニティ全体に影響を与えるアップデートと言えます。公式ブログも参照されており、技術的な深掘りが可能です。
