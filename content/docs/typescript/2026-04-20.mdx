### 1. Rust製TypeScriptネイティブコンパイラ「PerryTS」の登場

| 項目 | 詳細 |

| 投稿者 | azu (@azu_re) |
| 投稿日時 | 2026年4月19日 14:48（日本時間） |
| エンゲージメント | ❤️ 282 / 🔁 35 / 💬 0 |
| リンク | [元ポスト](https://x.com/azu_re/status/2045741429620986231) |

**投稿内容:**

> Rustで書かれたTypeScriptのネイティブコンパイラ。SWCでTypeScriptをパースし、LLVMで実行ファイルへと直接コンパイルする。macOS/Windows/Linux/iOS/Android向けのクロスコンパイルに対応し、ネイティブUIアプリの開発も可能になるプロジェクト「PerryTS」が注目を集めています。

**解説:**

TypeScriptコードをNode.jsやDenoなどのランタイムに依存せず、直接ネイティブの実行ファイル（単一バイナリ）にコンパイルできる新しいコンパイラ「PerryTS/perry」がGitHubで公開されました。内部では高速なTypeScriptパーサーとして知られるSWCを使い、LLVMを介して機械語に変換します。これにより、従来のJavaScript/TypeScript実行環境では避けられなかったランタイムオーバーヘッドが大幅に削減され、ベンチマークではNode.jsを24〜38倍上回るパフォーマンスを発揮しています。実用例としてネイティブゲームエンジンやGUIツール、AI搭載エディタなどがすでに作られており、TypeScriptの知識だけでデスクトップ・モバイルアプリを軽量に配布できる未来を示唆する技術動向として話題になっています。
