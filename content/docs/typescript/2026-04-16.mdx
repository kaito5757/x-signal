| 投稿日時 | 2026年4月15日 07:38（日本時間） |
| エンゲージメント | ❤️ 2 / 🔁 1 / 💬 0 |
| リンク | [元ポスト](https://x.com/TheThing89/status/2044319242607006028) |

**投稿内容:**

> 多くのTypeScriptプロジェクトで使ってきたが、それでも基本のJavaScriptを好む。TypeScriptの最大の価値はIntelliSense（コード補完）だが、それはJSDocを使えばJavaScriptでも実現可能。最大の欠点はコンパイルの遅さで、数百ミリ秒から数秒待たされるのが苦痛。単体テストがミリ秒単位で終わるJavaScriptの開発体験の方が優れていると感じる。

**解説:**

TypeScriptを長年実務で使用してきた開発者が、率直に「それでもJavaScriptの方が好き」と語った意見投稿。型安全性や開発ツールの利点は認めつつ、特にコンパイル時間の遅さが生産性を低下させると指摘。代替手段としてJSDocによる型ヒントを挙げ、TypeScript一択ではないという現実的な視点を提供している。TypeScriptの人気を背景に、弱点やトレードオフを議論する貴重な声として、技術選択時の参考になる内容。
