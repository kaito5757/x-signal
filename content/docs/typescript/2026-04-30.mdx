### 3. Cursorが公式TypeScript SDKを公開 – AIエージェント開発が容易に

| 項目 | 詳細 |
|------|------|
| 投稿者 | 宝玉 (@dotey) |
| 投稿日時 | 2026年4月30日 2:28（日本時間） |
| エンゲージメント | ❤️ 169 / 🔁 26 / 💬 14 |
| リンク | [元ポスト](https://x.com/dotey/status/2049541257756811517) |

**投稿内容:**

> Cursor 今天開放了官方 TypeScript SDK 公测，把驱动自家编辑器、CLI 和网页版的智能体（agent，可自主执行编码任务的 AI 助手）整套打包交给开发者。装上 npm install @cursor/sdk 就能用。调用方式很灵活。Agent 可以跑在本机，也可以塞到 Cursor 云端的独立虚拟机里。云端模式下每个 agent 都有专属沙箱、克隆好的代码仓库和配置完整的开发环境，电脑休眠或断网都不影响任务继续，干完活还能直接开 PR、推分支、附上截图。模型层面不绑定，OpenAI、Anthropic、Google 的前沿模型可以一键切换，也能跑 Cursor 自家的 Composer 2。SDK 把 Cursor 平时藏在编辑器里的那套 harness（智能体运行框架）整个开放了出来：代码库索引、语义搜索、即时 grep、MCP 工具接入、从仓库 .cursor/skills/ 目录自动加载的技能、可以观察和干预 agent 循环的 hooks，以及把任务拆给"子 agent"的能力。官方点名了几种典型场景：CI/CD 流水线里自动总结改动、定位失败原因、自动提修复 PR；做内部工具让销售和市场团队不写代码就能查产品数据；甚至把 Cursor 直接嵌进自家面向客户的产品里，让最终用户在不离开宿主应用的情况下用上 agent 体验。

**解説:**

AI支援コードエディタとして人気のCursorが、公式のTypeScript SDKを公開したことを詳しく解説した投稿です。このSDKを使うことで、Cursorが内部で使っているAIエージェント（自律的にコードを書いたり修正したりする機能）を、自分たちのアプリケーションやCI/CDパイプライン、内部ツールに簡単に組み込めるようになります。主な特徴はクラウド実行環境の提供（PCがオフラインでも動作）、多様なAIモデル対応、コードベースのセマンティック検索、スキル自動ロード、子エージェントへのタスク分割などです。TypeScriptで書けるため、Web開発者にとって親和性が高く、AIを活用した開発ワークフローを劇的に効率化する実践的なユースケースとして注目されています。OpenAIやAnthropicなどのモデルを切り替えられる柔軟性も大きなポイントです。
