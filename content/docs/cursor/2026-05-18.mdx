### 1. Cursorを本物のシニア開発者に変えるオープンソースツール「Superpowers」

**投稿内容:**

> 🚨今すぐClaude Code、Codex、Cursorを本物のシニア開発者に変えられます。100%無料です。
> 
> SuperpowersはGitHubで9万4千スターを超えました。
> 
> このツールの特徴:
> - エージェントに1行もコードを書く前にブレインストーミングを強制
> - 例外なくTDD（Red/Green）を実践（テストが先になければコードを削除）
> - git worktreeを使って並行サブエージェントを分離してオーケストレーション
> 
> 違いは歴然:
> 通常のClaude Code → いきなりコードを書いて盲目的にデバッグし、テストを放棄
> Superpowers使用時 → 7段階フロー: Brainstorm → Spec → Plan → TDD → Subagents → Review → Ship
> 
> テストが通るまで一切コードを書かない。
> 
> さらに: Claude Code、Codex、Cursor、Gemini CLI、OpenCode、Copilot CLIに対応。エージェントは計画から逸脱せず数時間自律的に動作。
> 
> 100%オープンソース（MITライセンス）。
> 大規模プロジェクトになるとエージェントは幻覚を起こし、テストを壊し、デッドコードを挿入し始めます。
> 
> Superpowersはシニアエンジニアのプロセスを強制し、コンテキストをコントロール下に置きます。
> 
> これでAIを使ったプログラミングが根本的に変わります。
> もう盲目的にプロンプトを書く必要はありません。エージェントがシニアエンジニアのように働きます。

**解説:**

この投稿は、Cursor（および他のAIコードエディタ）を単なるコード補完ツールから「本物のシニアエンジニアレベルの思考プロセスを持つエージェント」に変えるオープンソースプロジェクト「Superpowers」を紹介しています。従来のAIエージェントが陥りがちな「いきなりコードを書いて失敗を繰り返す」問題を、厳格な7段階の構造化ワークフロー（ブレインストーミング→仕様策定→計画→TDD→並行サブエージェント実行→レビュー→出荷）と、git worktreeによる分離環境で解決する点が技術的に優れています。特に大規模プロジェクトでのコンテキスト汚染や幻覚を防ぐ仕組みは実践的で、業界動向としてAIエージェントの「運用方法」の進化を示す内容です。GitHubで短期間に9万4千スターを集めた人気も反映され、優先すべき「具体的な技術Tips・ベストプラクティス」および「新機能・アップデート情報」に該当します。
